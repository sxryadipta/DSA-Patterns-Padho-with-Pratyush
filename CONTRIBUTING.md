
# Contributing

Thanks for taking the time to contribute! Here's how to do it cleanly.

## How to Contribute

1. **Fork** the repository and create a new branch:
   ```bash
   git checkout -b fix/two-pointers-typo
   ```

2. **Make your changes** — see guidelines below.

3. **Commit clearly:**
   ```bash
   git commit -m "fix: typo in Two Pointers notes"
   ```

4. **Open a Pull Request** with a short description of what you changed and why.

---

## Guidelines

- Follow the existing solution file format (problem link, pattern, TC, SC in comments at the top).
- One pattern or problem per PR, keep changes focused.
- If adding a new solution, make sure it's your own original work, not copied from discussion forums.
- If correcting a solution, explain the bug and your fix in the PR description.

## What's Welcome

- Bug fixes in existing solutions
- Better or alternative approaches to a problem
- Improvements to `notes.md` files
- Fixing typos or broken links

## What to Avoid

- Adding solutions in a different language than the repo's primary language
- Bulk-adding unrelated problems not covered in the course
- Reformatting files just for style preferences

---

If you're unsure whether something is worth contributing, open a Discussion first.
